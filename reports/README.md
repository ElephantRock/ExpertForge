# `reports/` — Experiment reports and decision records

Experiment reports distinguish observed result, plausible mechanism, causal
conclusion, and speculation (doctrine/evaluation-and-experiments.md §2). Negative
results and kill decisions are retained here as project evidence.

Durable architectural/process decisions are recorded under `doctrine/decisions/`,
not here; this directory holds experiment write-ups and analysis.

At scaffold time this directory contains only this purpose note.
